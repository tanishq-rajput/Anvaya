# ANVAYA

**Discover your style. Define your expression.**

Anvaya is a fashion styling and colour exploration web application designed to help users discover personal aesthetics, explore colour palettes, and find outfit inspiration.

### Features

- **Hue Atelier:** Explore colour palettes and discover colour combinations
- **Interactive Mannequin:** Visualise clothing combinations, colours, and garment details.
- **Style Exploration:** Explore different fashion aesthetics through an editorial-inspired interface.

### Tech Stack

React · Vite · JavaScript · CSS
